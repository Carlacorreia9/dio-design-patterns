# DIO - Design Patterns em Java

Projeto desenvolvido para o desafio da Digital Innovation One (DIO).

## Padrões de Projeto Implementados

### Singleton

Garante que apenas uma instância de uma classe exista durante toda a execução da aplicação.

### Strategy

Permite alterar comportamentos em tempo de execução através da composição de objetos.

### Chain of Responsibility

Permite que uma solicitação percorra uma cadeia de objetos até ser tratada.

## Tecnologias Utilizadas

* Java
* Programação Orientada a Objetos (POO)
* Design Patterns
